# DEEP SALVAGE

Кооперативный 3D-хоррор про переноску хрупкой добычи: 1–4 сальважёра, тёмный подземный склад,
физика предметов, монстр, который слышит и видит, квоты, эвакуация и возрождение напарников.

Игра написана с нуля: свой движок-обвязка поверх Three.js, свой сетевой сервер на Node.js,
процедурные уровни, процедурные текстуры и модели, синтезированный звук. Внешних ассетов нет —
ни моделей, ни картинок, ни звуковых файлов.

> **Важно про «точь-в-точь как REPO».** R.E.P.O. — коммерческая игра студии semiwork. Её код,
> модели, текстуры, звуки, названия и логотипы защищены авторским правом, поэтому копировать их
> (и выдавать за свои) нельзя. Здесь сделан **оригинальный** кооп-хоррор в том же жанре и с той же
> формулой: физика + переноска ценного груза + жадность + монстр + квоты + эвакуация.
> Всё остальное — своё: сеттинг, лут, чудовище, интерфейс, экономика.

## Быстрый старт (локально)

```bash
npm install
npm start
```

Откройте <http://localhost:3000>, введите позывной и код комнаты → «В ШАХТУ».
Сервер печатает адрес для друзей в локальной сети, например `http://192.168.1.20:3000/`.

Один раз нажать на экран нужно для захвата мыши и включения звука (политика браузеров).

## Игра с друзьями

1. Хост запускает сервер (или разворачивает его на VPS — см. ниже) и открывает игру.
2. В меню вводит код комнаты, например `BRIGADE`, и жмёт «В ШАХТУ».
3. Отправляет друзьям ссылку `http://<адрес>:3000/?room=BRIGADE`.
4. Все попадают в одну шахту, хосту доступна кнопка «НАЧАТЬ СМЕНУ».

Варианты, как дать доступ снаружи:

* **Одна сеть (Wi-Fi)** — просто адрес из лога сервера.
* **Интернет** — пробросить порт 3000 на роутере, либо поставить сервер на VPS
  (`npm install && PORT=8080 npm start`, открыть порт) и играть по `http://IP:8080/?room=КОД`.
  Для HTTPS-домена WebSocket автоматически переключится на `wss://` (клиент смотрит на протокол страницы).
* **Туннель** — любой туннель до порта 3000 (cloudflared, ngrok и т.п.), ссылку с `?room=КОД` — друзьям.

## Управление

| Клавиши | Действие |
|---|---|
| WASD | движение |
| Shift | бег (тратит дыхание, шумит) |
| Ctrl / C | красться (тише и незаметнее, но медленно) |
| Space | прыжок |
| E | взять предмет / положить / сдать в приёмник / поднять напарника (удерживать) |
| ЛКМ | швырнуть предмет |
| ПКМ | аккуратно положить |
| F | фонарь (свет выдаёт вас монстру) |
| Enter | чат |
| Tab | скрыть/показать бригаду |

## Правила смены

* Задача: набрать **квоту** деньгами и уйти живыми.
* Добыча валяется по всему уровню. Ценные вещи **бьются**: упавшее с высоты или швырнутое
  добро шумит и привлекает монстра.
* Приёмник (синий, с надписью) принимает предметы: подойдите и нажмите **E**.
* Когда квота набрана, платформа у входа загорается зелёным. **Вся живая бригада** должна
  простоять на ней ~5 секунд.
* Монстр патрулирует, слышит шум и видит свет/движение. Он бьёт больно, но после того,
  как свалил игрока, на пару секунд отвлекается — это окно на спасение.
* Упавший игрок истекает кровью 50 секунд. Напарник поднимает его удержанием **E**.
* Следующая смена: квота ×1.45, монстр чуть быстрее, новый уровень.
* Время смены — 12 минут. Кончилось время или погибла вся бригада — провал.

## Моды (контент-паки)

Папка `mods/`, файлы `*.json`, подхватываются при старте сервера (и по `POST /api/reload-mods`):

```json
{
  "name": "Мой пак",
  "quotaScale": 1.2,
  "monsterSpeed": 1.1,
  "items": [
    { "shape": "gem", "name": "Ампула", "value": 240, "color": "#8dff6e", "w": 0.22, "h": 0.3 }
  ]
}
```

Доступные `shape`: `vase`, `skull`, `statue`, `lamp`, `tv`, `crate`, `gem`, `orb`, `engine`, `painting`
(неизвестная форма рендерится как ящик). `name`, `value`, `color`, `w`, `h` — обязательны по смыслу.
Стартовый пример — `mods/example-pack.json`.

## Сборка .exe (Windows)

В песочнице, где писался код, Windows-бинарник собрать нельзя (нет wine и Windows-тулчейна),
поэтому в репозитории лежит готовая конфигурация Electron + electron-builder:

```bash
npm install            # подтянет electron и electron-builder (optionalDependencies)
npm run dist:win       # на Windows: dist/DeepSalvage 1.0.0.exe (portable + NSIS)
```

`desktop/main.js` поднимает тот же сервер внутри Electron и открывает окно — то есть exe
работает и как одиночная игра, и как хост: друзья подключаются по ссылке `http://IP:3210/?room=КОД`.
Запуск без сборки: `npm run desktop`. Linux-сборка: `npm run dist:linux`.

> Если `npm install` не смог скачать Electron (нет сети/прокси), игра всё равно полностью
> работает в браузере через `npm start` — Electron нужен только для настольного бинарника.

## Архитектура

```
server/
  index.js   Express + WebSocket, комнаты, раздача статики, моды, LAN-адрес
  game.js    авторитетная логика комнаты: физика лута, ИИ монстра (BFS + восприятие),
             квоты, эвакуация, возрождение, снимки состояния 20 Гц
  level.js   процедурная генерация: комнаты, коридоры, стеллажи, спавн лута/платформы/монстра
public/
  index.html, style.css   HUD, меню, оверлеи, пост-эффекты
  js/main.js   управление, коллизии, сеть, HUD, интерполяция
  js/world.js  процедурные текстуры (canvas), уровень, модели лута, аватары, монстр
  js/audio.js  синтез звука на WebAudio (шаги, рык, удары, сердцебиение, дрон)
scripts/
  playtest.mjs  интеграционный прогон на двух клиентах (сеть, лут, квота, эвакуация, монстр, revive)
```

Проверка после изменений:

```bash
npm start                 # в одном терминале
node scripts/playtest.mjs # в другом: 30+ проверок сетевой логики
```

Сервер авторитетен для лута, урона, квоты и монстра; клиент предсказывает только собственное
перемещение (с коллизиями по сетке уровня) и отправляет позицию 16 раз в секунду.
