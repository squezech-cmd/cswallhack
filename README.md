# Башни и руны

Оригинальная браузерная карточная стратегия в жанре lane battler: собирайте колоду, управляйте энергией, выставляйте воинов, запускайте руны и защищайте крепость. Доступны одиночные матчи с ботом трёх сложностей и сетевые дуэли с другом по коду комнаты.

Все иллюстрации карточек собраны из оригинальных CSS-эффектов и символов — сторонние игровые ассеты не используются. В проекте 24 доступные карты: воины, заклинания и постройки.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm start
```

Откройте <http://localhost:3000>. Для режима с ботом выберите сложность и нажмите «Начать бой». Для дуэли выберите «С другом», задайте код комнаты и поделитесь ссылкой или кодом. Для игры через интернет сервер должен быть доступен друзьям (например, на VPS или через туннель); для защищённого сайта используйте HTTPS, сервер автоматически принимает WebSocket-соединение через WSS.

## Как играть

1. Откройте «Моя колода» и выберите 8 карт из всего доступного набора.
2. Во время матча выберите одну из четырёх карт в руке.
3. Нажмите на одну из трёх линий арены. Воины и постройки размещаются на своей половине, руны можно направлять по всей линии.
4. Расходуйте энергию с умом: она постепенно восстанавливается, а в последнюю минуту восстанавливается быстрее.
5. Уничтожьте центральную башню соперника, чтобы победить.

## Проверка

При запущенном сервере выполните:

```bash
npm test
```

Интеграционный тест проверяет набор карт, матч против бота, розыгрыш карты и соединение двух игроков в комнате.

## Устройство проекта

- `server/index.js` — Express, комнаты WebSocket, серверный игровой цикл и логика боя.
- `public/index.html`, `public/style.css` — меню, арена и интерфейс.
- `public/js/app.js` — игровая отрисовка Canvas, колода и соединение с сервером.
- `public/cards.json` — характеристики всех доступных карт.
- `scripts/playtest.mjs` — интеграционные проверки.
