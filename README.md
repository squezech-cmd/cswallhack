# Burger Shift — фанатский кооперативный прототип

Небольшая самостоятельная браузерная игра, вдохновлённая **Burger Shift: Team Rush**. Это **не** официальная игра и не точная копия: оригинальные модели, механики и весь контент коммерческой игры недоступны в этом репозитории. Иллюстрация меню сгенерирована для этого проекта, кухня и предметы построены из собственных 3D-примитивов и векторной графики.

## Запуск

Нужен Node.js 20 или новее и npm.

```bash
npm install
npm run dev
```

Откройте **http://localhost:3000** в современном браузере с поддержкой WebGL. `PORT=8080 npm run dev` позволяет выбрать другой порт. Для продакшен-сборки:

```bash
npm run build
npm start
```

Для тестов: `npm test`.

## Кооператив по ID

1. Все игроки открывают **один и тот же адрес сервера**. Он должен быть доступен каждому из них и поддерживать WebSocket (`/ws`).
2. Создатель выбирает «Играть с друзьями» → «Создать лобби» и отправляет друзьям шестизначный ID либо приглашение-ссылку.
3. Остальные выбирают «Войти по ID» и вводят код. В комнате могут играть до **8 человек**; присоединиться можно и во время смены.
4. Создатель запускает смену. Если он выходит, управление лобби переходит следующему игроку.

Для игры в локальной сети откройте сервер по сетевому адресу компьютера, на котором он запущен, например `http://192.168.1.10:3000` (локальный IP и настройки брандмауэра у вас будут свои). Для игры через интернет нужен общедоступный HTTPS-сервер/туннель с поддержкой WebSocket. Адрес `localhost` на другом компьютере **не** подключает его к вашему серверу.

Комнаты хранятся в памяти сервера и удаляются, когда из них выходят все игроки или сервер перезапускается. Аккаунты, постоянные сохранения и голосовой чат не реализованы; есть текстовый чат.

## Управление

- **W A S D** — движение; **Shift** — бег.
- **Мышь** — обзор; при входе в кухню браузер запросит захват курсора. Если он недоступен, используйте стрелки для обзора.
- **E** или левая кнопка мыши — действие с ближайшей станцией, на которую вы смотрите.
- **Q** — выбросить предмет из рук.
- **H** или **Tab** — рецепты; **Enter** — чат; **Esc** — меню.
- На сенсорных устройствах доступны экранные кнопки движения и действий, а поворот камеры осуществляется свайпом по кухне. Удобнее играть с клавиатурой и мышью.

Смена и заказы продолжаются в реальном времени, даже когда открыта подсказка или меню.

## Что реализовано

- Трёхмерная кухня от первого лица, персонажи, анимация и общие станции.
- Совместные заказы, таймер терпения гостей, выручка, очки и несколько смен.
- Сырые котлеты и картофель, гриль и фритюр с приготовлением и подгоранием, стол сборки, булочки, сыр и необязательные овощи, газировка, кофе и стойка выдачи.
- Случайные события во время смены и улучшения кухни между сменами за общую выручку.
- Создание и вход в лобби по ID/ссылке, до 8 игроков, синхронизированные предметы и действия, текстовый чат, выбор цвета формы.

### Рецепты

- **Бургер:** булочка на стол сборки → готовая котлета → забрать со стола.
- **Чизбургер:** то же самое, но до получения бургера добавить сыр. Салат и томат необязательны.
- **Фри:** взять картофель → положить во фритюр → дождаться готовности и забрать.
- Напитки берутся из соответствующего автомата. Блюда из карточки заказа можно сдавать на выдаче по одному, в том числе разными игроками.
